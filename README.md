# 🌸 st10533149_webpart3 - Flower Shop Website

A simple, responsive website for a flower shop where customers can browse flowers, search the shop, view the gallery, and send enquiries.

Live site: https://glittering-genie-5e265e.netlify.app

## Pages

- **Index.html** - Home page
- **gallery.html** - Photo gallery with lightbox
- **shop.html** - Shop with live search
- **Enquiry.html** - Enquiry form with validation
- **contact.html** - Contact form
- **delivery.html** - Delivery info
- **occasions.html** - Flowers for different occasions

## Features

- Gallery lightbox - click a flower photo to view it bigger with caption
- Shop search - type in the search box to filter flowers live, shows how many results found
- Enquiry form validation - checks all fields are filled, checks email has @, shows error messages
- Contact form validation - checks all fields are filled, shows thank you message
- All JavaScript is in one file - `script.js` (no inline scripts in HTML)

## Technologies Used

- HTML
- CSS
- JavaScript (Vanilla JS - no frameworks)
